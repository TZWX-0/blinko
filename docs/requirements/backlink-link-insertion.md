# 双链正文插入与自定义展示文本需求

## 背景
当前“双链/引用笔记”功能仅在引用列表中建立关联，无法把引用链接插入到正文中，也无法自定义正文中展示的链接文本。用户需要在编写正文时直接插入指向目标笔记的链接，并能控制链接显示文案。

## 目标
- 在选择引用笔记后，将该引用以 Markdown 链接插入正文光标位置。
- 允许用户自定义链接在正文中的展示文本。
- 保留现有双链关联逻辑（引用列表）以维持反向引用能力。

## 非目标
- 不改动现有反向引用展示样式与逻辑。
- 不引入新的笔记标题字段或独立的“链接管理”页面。
- 不改变现有外部链接预览的行为逻辑。

## 用户故事
1. 作为笔记作者，我在编辑器中选择一条引用笔记后，希望能输入自定义的链接文字，并把链接插入当前正文光标处。
2. 作为笔记作者，我希望引用关系仍保留在引用列表中，方便查看双链。

## 功能需求
1. **选择引用笔记后弹出输入框**：
   - 弹窗显示“链接显示文本”的输入框。
   - 默认填充为目标笔记的内容摘要（首行/截断）。
2. **确认后插入 Markdown 链接**：
   - 按确认后，将 `[显示文本](/detail?id=<noteId>)` 插入正文光标位置。
   - 插入后保持编辑器焦点。
3. **保留引用关系**：
   - 仍将目标笔记加入引用列表，避免破坏双链。
4. **取消操作**：
   - 用户取消后不插入正文、不新增引用。

## 交互与文案
- 弹窗标题示例：“插入引用链接”。
- 输入框标签示例：“链接显示文本”。
- 占位符示例：“例如：阅读这篇笔记”。

## 验收标准
- 选择引用笔记后出现输入弹窗。
- 输入文本并确认后，正文光标位置出现 Markdown 链接，链接文本与输入一致。
- 引用列表仍新增该笔记（双链关联仍存在）。
- 取消操作不会插入正文或新增引用。
